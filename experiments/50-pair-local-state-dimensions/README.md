# Experiment 50 — pair-local state dimensions

For each of 1,964 ordered endpoint pairs, exact source-to-target geodesic states were enumerated and all minimum literal coordinate sets were enumerated.

```text
K_p: 2→1888, 3→22, 4→36, 5→2, 6→4, 7→12
I_p: 1→1888, 2→58, 3→18
m_R: 1→1888, 2→58, 3→18
m_A: 1→1888, 2→58, 3→18
m_R = m_A pairs: 1964 / 1964
max local literal dimension: 3
```

Each pair receipt preserves `K_p`, `I_p`, all minimum removal/addition coordinate sets, and their local backbones/supports. The shared global vocabulary remains 200 declarations; pair-local dimensions never exceed 3.

This is a pair-conditioned representation measurement, not a compression ratio or semantic dimensionality claim.
