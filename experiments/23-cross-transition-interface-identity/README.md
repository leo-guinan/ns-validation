# Experiment 23 — cross-transition interface identity

Experiment 23 compares the unique optimum gateway sets from Experiment 22 across all six frontier-expanding transitions. Forced locals and residual-backbone locals are compared separately.

Measured identity regularities:

```text
72-frontier pair:     identical 12-member optimum
2436-frontier trio:   identical 302-member optimum
2436 vs 2508:         293 shared members, 9 directional differences
72 vs 2436:           disjoint optimum identities
72 vs 2508:           the 12-member 72 optimum is contained in the 309-member 2508 optimum
```

No 2436 optimum is contained in the 2508 optimum. Conversely, the 72-member optimum is contained in the 2508 optimum but disjoint from the 2436 optimum. Similar width therefore does not imply a simple incremental interface extension.

These are identity facts under the fixed elaborated bipartite set-cover representation. They do not establish semantic equivalence, proof sufficiency, or runtime reusability.
