# Experiment 01 — lifecycle cost ledger

Status: locally checked, source evidence still unverified.

This experiment makes the six-stage lifecycle numerically inspectable without pretending that heterogeneous measurements are commensurate.

For each stage it records:

`L_i = (C_i, |S_i|, V_i, T_i, P_i)`

with construction, validation, and replay work kept separate. Native observations such as reported hours, messages, tokens, and proof pages remain in their original units. Missing costs, state sizes, and interface sizes are `null`/`unknown`.

The current output is generated by `verify.py`:

- `data/experiment01-ledger.json`
- `data/experiment01-report.txt`

The edgewise compression ratio remains explicitly unsupported until both exported-state size and sufficient interface size have a defensible common encoding. This is a result, not a blank to fill.

## Acceptance gate

A future revision may calculate a ratio only after it provides:

1. a declared size unit;
2. a source or measurement for both numerator and denominator;
3. compatible stage boundaries;
4. an independent readback or replay procedure.
