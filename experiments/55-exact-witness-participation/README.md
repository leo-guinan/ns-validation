# Experiment 55 — exact witness participation

Uniform-counting participation is computed from the factored global minimum-cover family.

```text
worlds:                    1964
backbone worlds:             62
optional-optimal worlds:   1852
never-optimal worlds:        50
sum participation:           188
backbone mass:                62
optional mass:               126
```

Component checks:

```text
120 substitution components: 120 participation units
5-component kernel:           10 participation units
  4 backbone units + 6 optional units
```

Optional participation ranges from `4/451` to `1/2`, with mean `63/926`. The 120 one-coordinate substitution components satisfy `p(w)=1/k_i` exactly. Exact participation numerators and denominators for the five kernel components are preserved.

Participation is a uniform-counting fraction over finite minimum covers, not an empirical probability, semantic necessity, or usage rate. The measured distinction is contract-scoped: the shared literal declaration vocabulary is coordinate-irredundant, while minimum-cover witness realization is highly non-unique.
