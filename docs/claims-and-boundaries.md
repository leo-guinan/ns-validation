# Claims and boundaries

## Current candidate claims

1. Hard global construction can sometimes be replaced by iterative cancellation of a compressed local residual.
2. More expensive discovery can justify cheaper future truth.
3. Different stages of truth production want different computational architectures.
4. Civilization can invest work upstream to create states whose truth is cheaper to reuse.

All four are `unvalidated` research hypotheses in this repository.

## Case-study boundaries

- The source is a local Markdown note, not an independently checked bibliography.
- Reported, derived, estimated, and modeled quantities are kept separate.
- The repository does not verify the alleged Navier–Stokes result or prize status.
- The repository does not measure the original agent search, Lean formalization, or kernel runtime.
- The first implementation measures ledger structure and graph representation, not mathematical validity.

## Next falsifiers

- A stage graph that cannot identify a concrete exported artifact.
- A proposed interface whose receiver needs omitted history to verify the next transition.
- A cost ratio whose numerator/denominator use incompatible units or provenance.
- A reuse benefit that disappears after verifier construction and maintenance costs are charged.
