# Research question

## Central question

> How does an expensive mathematical search become a progressively cheaper, more durable object of trust?

This repository studies validation architecture, not the truth of a new Navier–Stokes solution. The first case study is a source-bounded reconstruction of a reported discovery/formalization lifecycle.

## First milestone

Build an evidence-backed ledger and explicit stage graph for:

`search -> candidate insight -> proof construction -> formalization -> kernel verification -> reuse`

For each transition, record:

`(work, state exported, verification burden, trust assumptions)`

## Falsifier

The working thesis is weakened if the next stage requires essentially the full prior history, or if the proposed exported interface cannot support an independently specified verification task. A compact description is not automatically a sufficient interface.

## Status

`prospective`: the current ledger contains source-reported, derived, estimated, and modeled fields, but does not independently verify the underlying public claims.
